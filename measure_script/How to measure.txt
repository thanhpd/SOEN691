cd measure_script

** Pre-processing:
1. After generating the outputs as .msg file then but all the data under generated_msg folder
2. Run run_tokenizer.py
3. Once finished running, find the output files under the folder called "processed_msg"


** Run metrics (BLEU, Rouge-L, Meteor)
1. Run run_metrics.py
2. Once finished running, see the output in output.csv

** To run BERTScore
1. Install "pip install bert-score"
1. Run run_bertscore.py
2. Once finished running, see inside the bert_score folder for "output_bert.csv"

** To run BERTScore per line
1. Install "pip install bert-score"
1. Run bertscore_per_line.py
2. Once finished running, see inside the bert_score folder for "output_bert_per_line.csv"
